# Artes da LS Design

Coloque seus próprios flyers aqui (não inclua trabalhos de terceiros sem autorização).

Tamanhos sugeridos: feed 1080×1350; story 1080×1920; quadrado 1080×1080; paisagem 1600×900. Exporte AVIF e WebP quando possível e preserve JPEG/PNG como fallback.

No `index.html`, configure os dados do projeto em `CONFIG.projects`: `id`, `slug` único, `title`, `category`, `featured`, `alt` descritivo, `order`, `image:{src, avif, webp, width, height}`. Configure as dimensões exatas da imagem para evitar layout shift. Se `image` ficar `null`, será usado um pôster conceitual.

Não há CMS nem upload no site público nesta versão. Nunca coloque credenciais ou informações particulares nesta pasta.
